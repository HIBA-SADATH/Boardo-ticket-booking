# 🎫 Boardo – Online Ticket Booking System

Boardo is a Django-based online ticket booking platform designed to provide users with a convenient way to search, book, and manage tickets for different travel and event categories.

The system includes user authentication, trip search, seat selection, traveller management, online payments, booking management, agency features, reviews, favourites, notifications, customer support, and an AI chatbot.

---

## 🚀 Features

### 👤 User Features

- User registration and login
- User profile management
- Search trips by source, destination, category, and departure date
- View available trips
- View trip details
- Seat selection
- Traveller management
- Book tickets
- View booking history
- Manage bookings
- Cancel bookings
- Favourite trips
- Reviews and ratings
- Notifications
- Customer support
- AI chatbot assistance

### 🚌 Travel & Ticket Booking

Boardo supports different booking categories:

- 🚌 Bus
- 🚆 Train
- ✈️ Flight
- 🎟️ Events

Users can search for available trips and select seats before confirming their booking.

### 💺 Seat Management

- Interactive seat selection
- Seat availability tracking
- Booked seat identification
- Passenger/traveller details
- Seat assignment for bookings

### 💳 Payment

Boardo integrates online payment functionality using **Razorpay**.

The payment system handles:

- Payment order creation
- Payment processing
- Payment verification
- Payment status
- Booking confirmation

### 🏢 Agency Features

Agencies can manage their travel services through an agency dashboard.

Features include:

- Vehicle management
- Trip management
- Category management
- Agency reports
- Booking information
- Travel service management

### 🤖 AI Chatbot

Boardo includes an AI chatbot interface to assist users with travel and booking-related interactions.

### ⭐ Reviews & Favourites

Users can:

- Rate and review trips
- Save favourite trips
- View their favourite travel options
